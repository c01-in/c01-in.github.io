# Kotlin Playground

一个基于浏览器的Kotlin代码编辑和运行环境，让您可以在不安装任何工具的情况下体验Kotlin编程。

## 功能特性

### 🚀 代码编辑器
- **语法高亮**: 支持Kotlin语法高亮（基于Java语言支持）
- **智能补全**: 内置Kotlin关键字和常用函数补全
- **快捷键支持**: 提供IDE级别的编辑快捷键
- **字体切换**: 支持系统字体和自定义字体切换

### 📝 代码模板
内置多种实用的代码模板：
- **Hello World**: 简单的入门示例
- **Basic Functions**: 基础函数定义和调用
- **Collections**: 集合操作示例
- **Data Classes**: 数据类使用示例
- **Coroutines**: 协程基础示例
- **Android UI**: Android UI组件模拟

### 🎯 代码执行
- **模拟执行**: 在浏览器中模拟Kotlin代码执行
- **智能输出**: 根据代码内容生成相应的模拟输出
- **实时反馈**: 执行状态和结果实时显示

### 💾 文件管理
- **本地存储**: 自动保存代码到浏览器本地存储
- **导入导出**: 支持.kt文件导入和导出
- **文件命名**: 自定义文件名和扩展名

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+/` | 切换注释 |
| `Ctrl+D` | 复制当前行 |
| `Ctrl+L` | 选择当前行 |
| `Ctrl+K` | 删除当前行 |
| `Ctrl+J` | 合并下一行 |
| `Tab` | 增加缩进 |
| `Shift+Tab` | 减少缩进 |

## 使用方法

1. **选择模板**: 点击"Templates"按钮选择预定义的代码模板
2. **编写代码**: 在左侧编辑器中编写或修改Kotlin代码
3. **运行代码**: 点击"Run"按钮执行代码
4. **查看结果**: 在右侧输出面板查看执行结果
5. **保存代码**: 使用"Save"按钮保存到本地存储
6. **导出文件**: 使用"Export"按钮下载.kt文件

## 技术实现

- **前端框架**: React 19 + TypeScript
- **代码编辑器**: CodeMirror 6
- **UI组件**: shadcn/ui + Tailwind CSS
- **状态管理**: React Hooks + Local Storage
- **主题支持**: 明暗主题切换

## 注意事项

- 这是一个**模拟执行环境**，不会真正编译和运行Kotlin代码
- 输出结果是基于代码内容的智能模拟
- 建议在真实开发环境中测试代码的正确性
- 支持现代浏览器，推荐使用Chrome、Firefox、Safari或Edge
